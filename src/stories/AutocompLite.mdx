`AutocompLite` allows to find `multiple key values pretty fast` while presenting them to the user `highlighted` if matching `search query` (if that makes any sense). User can then select one or many...

We shall accept any shaped data, given an Array of `T` we'll use a `mapper function` to build the `full search option`, as in:

```ts
const PLACES = [
  {
    id: "paris",
    city: "Paris",
    state: "Île-de-France",
    country: "France",
    continent: "Europe",
  },
  //...
];

const mapper = (p: (typeof demoPlaces)[number]): AutocompLiteOption => ({
  id: p.id,
  city: p.city,
  state: p?.state ?? "",
  country: p.country,
  continent: p.continent,
  full: `${p.city}${p.state ? `, ${p.state}` : ""}, ${p.country}`,
});
```
